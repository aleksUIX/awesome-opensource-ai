# Contributing

Pull requests welcome. Before opening one:

1. Check the project is not already listed.
2. Check it's genuinely open source: a real OSI-style license (Apache 2.0, MIT, CC0, etc.), not just "open weights" behind a restrictive custom license.
3. Check it's actively maintained: a commit or release within the last 6 months, unless it's listed deliberately as a historically significant but stalled project.
4. Add one line, in the right category, in this format:

   ```
   - **[Name](https://github.com/org/repo)** ![GitHub stars](https://img.shields.io/github/stars/org/repo?style=flat-square&label=%20): One sentence, factual, no marketing language.
   ```

5. Sort new entries into their category by star count, descending, unless there's a good reason not to (e.g. grouping a product with its underlying engine).
6. One project per pull request, so it's easy to review.

If a project no longer fits (archived, relicensed to something non-open, or superseded), open a PR removing or updating it instead.
